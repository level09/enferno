## Overview

Enferno ships two pieces of context for coding agents:

- **`AGENTS.md`**: a short, always-loaded guide with the stack, layout, commands, routes and hard rules. Claude Code, Codex, Cursor, GitHub Copilot and most other agents read it automatically.
- **The `enferno-dev` skill** in `.agents/skills/enferno-dev/`: full code patterns for models, APIs, Vue pages, dialogs and migrations. Agents load it only when a task needs it, so it costs nothing the rest of the time.

`.agents/skills/` is the shared location for Codex, Cursor, Copilot, Gemini CLI, OpenCode and others. `.claude/skills` is a symlink to it, so Claude Code sees the same skill.

## Using It

Open the project in your agent and ask for features in plain language:

```
> Add a Product model with name, price and category, plus an admin page to manage it
> Add a status column to users and a migration for it
> Create an API endpoint to export activities as CSV
```

## Using the Skill in Another Project

Install the skill into any project with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add level09/enferno
```

## Customizing for Your Project

Add project-specific rules to `AGENTS.md` and keep it short. Put longer patterns in a skill under `.agents/skills/<name>/SKILL.md` so they load only when relevant.
